# Getting Support for WikiGerritTracker

Thank you for using **WikiGerritTracker**! Here is how you can find assistance, report problems, and participate in community discussions.

---

## Where to Get Help

### 1. Bug Reports & Feature Requests
If you encounter a bug or have a suggestion for improving repository classification or reporting:
- Check existing issues in the [GitHub Issue Tracker](https://github.com/wikimedia/wikigerrittracker/issues) to see if the topic is already discussed.
- If not, submit a new report using our [Bug Report Form](https://github.com/wikimedia/wikigerrittracker/issues/new?template=bug_report.yml) or [Feature Request Form](https://github.com/wikimedia/wikigerrittracker/issues/new?template=feature_request.yml).

### 2. General Questions & Usage Discussions
- Use the **GitHub Discussions** tab on this repository for general questions, scholarship dossier tips, and feature ideas.
- For MediaWiki technical questions or Gerrit tutorials, refer to the [MediaWiki Gerrit Tutorial](https://www.mediawiki.org/wiki/Gerrit/Tutorial).

### 3. Wikimedia Community Channels
- **IRC / Matrix Channels:** `#wikimedia-tech` on Libera.Chat.
- **Wikimedia Phabricator:** [Phabricator](https://phabricator.wikimedia.org/)

---
